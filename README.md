## 👋 Sobre

Sou **desenvolvedor**. Gosto da parte em que a ideia vira tela, a tela vira produto e o produto
roda de verdade na máquina de alguém — com performance, acessibilidade e acabamento.

- 🎯 **Front-end em primeiro lugar.** React + TypeScript, design system próprio, WCAG e Core Web Vitals como régua.
- 🧩 **Full-stack quando precisa.** Python/FastAPI, Node, SQLite, Redis — API enxuta para sustentar a interface.
- 🐧 **Linux nativo.** Plugins QML/Quickshell, Wayland, PipeWire, Arch. Ferramenta que eu uso todo dia.
- 🤖 **Automação com propósito.** Scraping, bots e CLIs que eliminam trabalho repetitivo.
- 🩺 **Saúde.** Plataformas de estudo e presença digital para estudantes e profissionais de medicina.
- 🇧🇷 Belo Horizonte, Brasil · pt-BR e inglês técnico.

## 🚀 Projetos em destaque

### 🩺 Scalpel — plataforma unificada de saúde

> Hub de apps para estudantes e profissionais de medicina: dashboard, login único,
> calendário acadêmico e flashcards com repetição espaçada (SM-2), tudo sob o mesmo domínio.
>
> **O que mudou:** `cmmg-calendar` e `mvp-estetoscopio` foram **descontinuados como repositórios
> isolados** e migraram para o Scalpel. Os repositórios antigos ficam arquivados apenas como histórico.
>
> `Next.js` · `React` · `TypeScript` · `Vite` · `PHP 8.3` · `SQLite` · `monorepo`
